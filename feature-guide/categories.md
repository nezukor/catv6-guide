# Categories

## Available Categories

- **Combat** — Aim assist, killaura, reach, velocity  
  `vape.Categories.Combat`
- **Blatant** — Fly, speed, hitboxes, longjump  
  `vape.Categories.Blatant`
- **Utility** — Auto tools, scaffold, staff detector  
  `vape.Categories.Utility`
- **Render** — ESP, nametags, tracers  
  `vape.Categories.Render`
- **World** — Block placing, schematics  
  `vape.Categories.World`
- **Inventory** — Auto buy, auto hotbar  
  `vape.Categories.Inventory`
- **Kits** — Kit-specific features  
  `vape.Categories.Kits`
- **Legit** — Subtle / legit features  
  `vape.Legit`
