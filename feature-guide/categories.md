\# Categories



\## Available Categories



| Category              | Use Case                              |

|-----------------------|---------------------------------------|

| `vape.Categories.Combat`     | Aim assist, killaura, reach, velocity |

| `vape.Categories.Blatant`    | Fly, speed, hitboxes, longjump        |

| `vape.Categories.Utility`    | Auto tools, scaffold, staff detector  |

| `vape.Categories.Render`     | ESP, nametags, tracers                |

| `vape.Categories.World`      | Block placing, auto tool, schematica  |

| `vape.Categories.Inventory`  | Auto buy, auto hotbar, armor switch   |

| `vape.Categories.Kits`       | Kit-specific features                 |

| `vape.Legit`                 | Legit / subtle features               |



\*\*Example:\*\*

```lua

vape.Categories.Blatant:CreateModule({...})
